# Proyecto Portfolio de Ilustración
Sitio web realizado para el curso de Desarrollo Web de Coderhouse.

## Sobre el sitio
Este sitio web representa el portfolio de una ilustradora(?). Incluye distintas secciones donde se presentan sus trabajos, servicios y formas de contacto.

## Herramientas utilizadas
- **Preentrega 1:** HTML
- **Preentrega 2:** CSS
- **Preentrega 3:** Box Model y Flexbox
- **Preentrega 4:** CSS Grid y Media Queries
